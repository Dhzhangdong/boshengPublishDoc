# AI接待员产品说明书

AI接待员（AIReceptionist）面向企业网站提供在线咨询服务：利用企业知识资料回答访客问题，在访客确认后记录需要人工跟进的工单，并通过管理后台管理资料、站点、会话、团队和用量。

本说明书按使用任务拆分为多个 Markdown 文件，图片保存在本目录的 `images/` 中。整目录复制后仍可浏览章节和截图。

## 推荐阅读路线

- **企业管理员：**快速入门 → 知识资料 → 站点与允许来源 → 网站安装 → 工单分类 → 成员与权限。
- **接待操作员：**知识资料 → 工单分类与处理 → 会话与审计 → 常见问题。
- **网站维护人员：**站点与允许来源 → 网站安装与访客使用。
- **平台运营人员：**平台运营 → 套餐与用量 → 适用范围与截图说明。

## 开始前准备

准备企业自用的注册手机号、可以对外回答的产品或服务资料、企业网站来源（协议、域名及端口），以及需要人工跟进的需求分类。先在自己的站点完成测试，再分享接待链接或安装网站组件。
