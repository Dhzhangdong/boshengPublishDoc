## 查看咨询过程

1. 选择目标空间，进入“会话”。
2. 按标题搜索或状态筛选，找到咨询记录。
3. 点击“详情”，查看访客与接待助手的对话和来源情况。

当前后台显示根会话的只读文本，不能在详情中代替访客发言，也不提供实时人工接管入口。咨询详情不等同于内部子任务、工具执行和推理过程的完整调试记录。

| 页面内容 | 作用 |
| --- | --- |
| 标题、站点、创建时间 | 识别咨询所属入口和发生时间 |
| 状态 | 区分处理中、等待回复、失败、关闭等记录 |
| 处理说明 | 查看失败原因或空闲自动结束原因 |
| 对话详情 | 查看访客和助手消息 |
| 来源 | 查看来源类型及匹配结果 |

## 导出会话

企业管理员和操作员可点击“导出”，下载 JSON 文件，包含标题、创建时间及对话消息。当前下载格式不是 Word、PDF 或 Excel。只读角色没有会话导出权限。

## 关闭与撤权

具有操作权限的成员可点击“关闭/撤权”并确认，结束咨询并撤销访客的访问授权。历史记录和工单保留。授权撤销遇到服务异常时后台继续重试，访客端可开始新咨询。

默认空闲自动结束从访客最后一次发送消息起计算，连续 10 分钟无新访客消息时结束。工单反馈消息也算活动；助手消息、刷新、打开窗口和授权续期不重新计时。服务端定期检查，因此实际提示可能稍晚于设定时长。访问上游消息异常时会延后判断，避免误关闭。

## 来源信息

| 展示名称 | 含义 |
| --- | --- |
| 直接访问 | 没有可用的推广或来源上下文 |
| 来源网站／来源页面 | 可用的网站来源或页面信息 |
| 推广参数 | 使用已允许的 UTM 参数 |
| 推广来源 | 使用推广来源码，配置齐备时可解析推广上下文 |
| 已匹配／未匹配 | 来源解析的匹配结果 |
| 来源查询暂不可用／未配置 | 对接未完成或暂时失败，不能据此判定推广活动无效 |

推广增强需要平台配置服务地址、认证及企业／空间开关。来源解析失败会降级为普通接待，不应把它理解为业务咨询必然失败，也不应把来源匹配等同于成交归因。

## 操作审计

进入“审计”，按时间查看操作名称、目标、结果和操作者，核对资料上传、工单处理、站点配置、成员管理、套餐确认等动作。

审计记录用于追踪团队操作，业务结果仍以对应页面为准。例如资料上传成功后仍要检查索引，套餐收款确认后仍要检查额度同步。成员删除后，相关业务历史和审计保留。
