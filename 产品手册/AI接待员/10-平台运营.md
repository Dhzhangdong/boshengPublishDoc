# 10 平台运营

[说明书目录](README.md) · [上一章：成员与权限](09-成员与权限.md) · [下一章：常见问题与排障](11-常见问题与排障.md)

本章适用于平台运营账号。企业账号不会显示“收款开通”“租户”“空间配置”三个平台页签。

## 企业开户与空间

手机号首次登录会自动创建企业、管理员、默认空间及站点，并按免费套餐申请开通独立接待服务实例。远端开通失败不会撤销本地注册，系统复用原开通请求重试，企业套餐页显示“接待空间正在开通”。

平台可在“租户”维护企业名称、启用状态、每日新建会话上限和资料数量上限；每日会话业务限额按界面标注的世界协调时间（UTC）统计，区别于套餐月额度的北京时间自然月。

“空间配置”管理租户归属、空间名称、服务实例、接待助手、配额模板和启用状态。手工新增空间前，应由平台维护人员先准备正确的上游实例及授权；不能把其他企业的实例作为本企业空间使用。企业普通成员没有助手提示词或任意工具配置入口。

## 收款确认

1. 在“收款开通”找到企业提交的待确认申请。
2. 核对企业、套餐、金额及实际到账情况。
3. 点击“确认收款”，填写真实且唯一的财务收款凭证／流水号。
4. 提交后检查申请状态、企业付费到期和“当前接待额度”。

收款记录先保存，随后同步额度。远端同步失败时付款记录和本地套餐保留，不应重复登记收款或重复续期。可等待自动重试，或由管理员在企业套餐页“重试同步”。同套餐续费与升级计期见[套餐与用量](08-套餐与用量.md)。

## 停用与删除企业

停用用于停止服务，禁止新授权并关闭相关会话；已有授权的远端撤销由后台重试完成。需要永久清理时，平台在“租户”点击“删除”，输入完整企业名称后确认。

| 影响范围 | 永久删除企业的处理 |
| --- | --- |
| 企业、空间、站点 | 停用并最终清理 |
| 成员账号和登录 | 停用、撤销登录并清理 |
| 知识资料和版本 | 清理 |
| 会话、授权、工单和处理历史 | 清理 |
| 套餐申请与收款记录 | 随本地企业数据清理 |
| 手机注册自动开通的服务实例 | 校验归属后删除 |
| 早期手工映射的实例 | 实例保留，撤销本企业会话授权 |
| 操作审计 | 保留 |
| 上游不可变 Token 消耗账本 | 按上游规则保留 |
| 跨企业共享访客 | 不因单一企业删除而删除 |

平台账号所属企业和当前账号所属企业受保护。删除后原业务数据无法通过产品恢复；如需保留资料或财务记录，应在删除前完成必要归档。

## 删除处理中与重试

远端清理失败或返回结果丢失时，企业立即停用，页面显示“删除处理中（自动重试）”，后台持续恢复清理，也可点击“重试删除”。删除处理中不能重新启用企业或继续配置。

完成后，该手机号可重新获取验证码并注册新企业，新企业不继承旧业务数据。删除最后一个企业后，系统重启不会重新创建默认企业。

## 上线前核对

确认目标 Web/API 版本、数据库迁移、接待助手发布状态、空间实例、套餐模板、公网证书与工单回调可用。使用正式资料的测试站点完成问答与确认工单链路，检查真实网站来源和手机嵌入环境，再开放客户入口。

详细部署、备份及服务端配置由受控项目运维文档维护，本产品手册不包含凭据、API 密钥或数据库连接配置。
