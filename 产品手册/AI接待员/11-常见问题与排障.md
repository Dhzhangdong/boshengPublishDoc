## 按现象排查

| 现象或提示 | 优先检查 | 处理方式 |
| --- | --- | --- |
| 收不到验证码 | 手机号、60 秒间隔、发送次数限制、短信服务状态 | 等待提示允许后重试；持续失败联系平台 |
| 验证码错误或过期 | 是否为最新验证码、是否超过 5 分钟 | 按页面提示重新获取，不连续反复输入 |
| 接待空间正在开通 | 首次注册的实例开通状态 | 等待并刷新；管理员点击“重试开通” |
| 接待额度正在同步 | 套餐变更后的同步状态 | 等待后台重试，或管理员“重试同步” |
| 文件被拒绝 | 后缀、20 MiB 大小、UTF-8、Office 宏和结构 | 修正文件后上传 |
| 资料已保存但推送失败 | 错误原因、配额、开通状态、服务可用性 | 恢复后点击原记录“重试推送” |
| 上传后答不上来 | 当前空间、本站点链接、索引就绪、正文是否含答案 | 检查索引，补充资料，以新咨询验证 |
| 新版本文件名不匹配 | 新文件与原资料名称 | 保留原文件名再提交 |
| 同名资料已被删除 | 原资料删除状态 | 先恢复原资料，再上传新版本 |
| 当前来源不在允许名单 | 协议、域名、端口、站点是否一致 | 补充正确来源，保存并刷新网站 |
| 独立页正常，嵌入打不开 | 企业网站来源、CSP、第三方访问限制 | 网站维护人员检查；使用新窗口入口 |
| 提示会话已结束 | 手动关闭、管理员撤权或空闲自动结束 | 点击“开始新咨询”，旧历史保留 |
| 没有工单确认卡片 | 站点工单开关、有效分类、信息和需求是否匹配 | 配置分类，用新咨询测试人工跟进需求 |
| 已批准但无工单记录 | 服务提交结果、容量、分类和会话当前状态 | 以后台列表为准，记录错误并联系平台 |
| 工单记录已达上限 | 保有量是否达到套餐容量 | 删除不再需要的记录，或升级 |
| 工单已被其他成员修改 | 最新状态、处理人和备注 | 刷新后核对，再保存 |
| 不能删除成员 | 是否自己、平台账号、最后一位启用管理员 | 先安排另一位管理员；受保护账号不删除 |
| 本月上下文额度已用完 | 企业全部空间总用量、重置时间 | 等待北京时间月初重置或升级 |
| 用量同步失败 | 最后成功同步时间及服务状态 | 数据可能过时；稍后重试并联系平台 |
| 接待服务尚未开通／配置不一致 | 空间实例、助手发布和平台映射 | 平台核对配置，企业无需反复注册 |
| 租户删除处理中 | 远端清理状态 | 平台等待或重试删除，不能重新启用 |

## 常见理解问题

### 修改企业名称后，访客为什么还看到旧名称？

企业名称与站点展示名独立。到“站点”更新“企业展示名”，保存后刷新接待页面。

### 设置人工服务时间后，AI 为什么仍然可用？

服务时间字段用于说明人工服务安排，不自动限制 AI 时段。暂停入口请使用站点启用开关。

### 解决或关闭工单，为什么容量没有减少？

工单上限统计保留记录数量。解决和关闭仍占容量，永久删除才释放；删除后正文和处理历史不可恢复。

### 1M 用量相当于多少次咨询？

无法换算为固定次数。问题长度、回答长度、上下文和处理过程不同，用量也不同；以实际输入输出 tokens 统计为准。

### 可以在后台直接接管访客聊天吗？

当前后台提供会话只读查看、导出和关闭。需要人工跟进时，通过工单分配及已收集联系方式继续沟通。

### 资料不足时，助手的回答能作为价格或政策承诺吗？

关键价格、政策和服务条件应与企业正式资料核对。发现答案缺失或歧义，应补充资料并安排人工确认，不仅根据模型输出作承诺。

## 向平台反馈问题

反馈时提供：发生时间与时区、所在页面和步骤、企业／空间／站点名称、工单或会话编号、完整中文错误提示；如果错误中有追踪编号，也一并提供。截图先遮盖客户联系方式和其他无关信息。

不要提供短信验证码、密码、API 密钥或完整配置文件。优先保留原失败记录，避免反复新建会话、重复上传或重复申请付款造成核对困难。
